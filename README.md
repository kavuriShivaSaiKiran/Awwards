# 🏆 Awwwards-Winning Website (Zentry Clone)

A visually stunning, award-winning frontend application built to showcase advanced micro-animations, seamless scroll effects, and modern UI/UX design. 

This project was developed following the comprehensive tutorial by [JavaScript Mastery](https://www.youtube.com/watch?v=zA9r5zTllx4) and is heavily inspired by the Awwwards Site of the Day winner, **Zentry**.

## 🌟 Features

- **Advanced Video Transitions**: A dynamic hero section featuring full-screen video backgrounds with seamless hover transitions that expand upon interaction.
- **Animated Floating Navbar**: A responsive, sticky navigation bar featuring custom audio/music toggle animations.
- **GSAP Scroll Animations**: Butter-smooth scroll triggers that animate text reveals and image transitions as you navigate down the page.
- **Interactive Bento Grid**: A trendy, modern bento box layout featuring a 3D card tilt effect that tracks cursor movement.
- **CSS Clip-Path Magic**: Custom geometric shapes for image containers utilizing modern CSS masking and clip-paths.
- **Fully Responsive**: Developed with a mobile-first approach, ensuring a flawless and highly performant experience across all devices.

## 🛠️ Tech Stack

- **Framework**: [React.js](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [GSAP (GreenSock Animation Platform)](https://gsap.com/)
